# SQL Playground Pro 🚀

An in-browser interactive SQL environment powered by **sql.js** (SQLite compiled to WebAssembly). Write, execute, and inspect SQL queries directly in your browser without any backend server required.

![SQL Playground Pro](https://mmarifkuet.github.io/sql-sandbox/)

## 🌐 Live Demo
Access the live application here: [https://mmarifkuet.github.io/sql-sandbox/](https://mmarifkuet.github.io/sql-sandbox/)

## ✨ Key Features
- **In-Browser Execution:** Full SQLite database capabilities using WebAssembly.
- **Dynamic Schema Explorer:** Displays available tables automatically.
- **Query History:** Persists executed queries using `localStorage`.
- **Export Capabilities:** Download query results directly as CSV files.
- **Quick Templates:** Pre-loaded SQL queries for instant testing.
- **Modern IDE Theme:** Dark mode user interface built with HTML5 & CSS3.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Database Engine:** [sql.js](https://github.com/sql-js/sql.js) (SQLite in WebAssembly)
- **Deployment:** GitHub Pages
